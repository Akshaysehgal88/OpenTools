# Usage conventions

## Start with one module

Use a completed run or a pair of saved artifacts. Keep the simulator, build system,
testbench, CI and report locations already in use. Load the module skill in your
AI agent and follow its README. The optional helper is one analysis method; native
company tools can supply additional evidence.

## Keep evidence traceable

Copy a template before editing it. Retain original reports and identify the source,
revision or content digest of each important observation. Manual review templates
and executable helper inputs are separate formats; check the module's FORMAT.md.

Keep unknown values unknown. A missing artifact is not a pass, an unobserved item
is not proven removed, and a current checkout does not establish what an older run
consumed. Preserve native failures, partial results and unsupported interpretations.
Separate source facts, AI interpretation, proposed actions and approved policy.

## Adapt locally

Map local field names, stages, test IDs and units explicitly. Preserve the native
values and document transformations. Qualify exporters against actual artifacts,
including failed and incomplete cases, before using their declarations in CI.
Keep review and acceptance authority in the existing engineering process.

## Handle company material

Store populated records, reports, waveforms, manifests and adapter settings in the
company's approved locations. These can expose design names, paths, configurations
or credentials. Use an AI host approved for that material. Bundled scripts do not
send artifacts to a model; an AI host applies its own data handling.

## Evaluate adoption

Start with advisory output, then automate collection where field meaning is clear.
Compare the same engineering task and configuration. Include setup, execution,
replay, collection, storage and review effort. Confirm that the required evidence
was retained before describing a cost reduction as an improvement.

Use the [project-local installer](INSTALL.md) for selected modules.
[Context adapters](CONTEXT_PORT.md) are optional and never install DVIT automatically.
