# Result applicability review

Load [SKILL.md](SKILL.md) from the clone or use the
[project-local installer](../../INSTALL.md) with your existing AI agent and model
subscription. No inference SDK or additional model account is required.

## Request

> Check whether this saved run supports the requested handoff configuration and claim. Inspect original executable, checker, firmware and input evidence. Preserve mismatches and unknowns, and save a cited review.

## Inputs

Provide the request, original result/build manifests, retained artifact and any existing approved reuse rule. Select fields relevant to the claim. Do not substitute current checkout hashes for original execution inputs.

## Review output

Retain the request, snapshot, native result, reuse record and machine report. Cite exact fields and native record locations. Preserve failed outcomes; correspondence does not establish checker sufficiency or approve a reuse exception.

The AI can use existing company tools or a separately validated method beyond the
bundled helper's profile. Preserve the helper's actual findings and label independent
interpretation. Check citations against original artifacts.

Optional [context sources](../../CONTEXT_PORT.md) can supply scoped evidence,
questions and helper descriptions. Standalone use requires no DVIT connection and
never installs DVIT. Bundled scripts do not send records to a model; use the host's
approved data handling for company material.
