# Equivalence review handoff

- **Question:** ECO, receiving owner, required behavior/modes and intent source.
- **Compared designs:** original sources, resolved parameters, elaborated identities.
- **Boundary:** reviewed input/output map and approval basis; partition population,
  exclusions, state, memory, blackbox, reset and X semantics.
- **Native observation:** engine/profile, original run, completion, verdict,
  restrictions and exact counterexample scope. Cite retained artifacts.
- **Applicability:** matching facts, known differences and missing evidence.
  Preserve an outside-scope witness without extending its conclusion.
- **Action:** smallest missing artifact or proposed correction, receiving owner,
  existing approval path and affected recheck. No action if evidence answers the claim.
- **Limits:** broader claims still open, supplied declarations versus measured facts.

Keep the engineering conclusion distinct from the original native outcome.
Attach normalized inputs and JSON/Markdown output when using the helper.
