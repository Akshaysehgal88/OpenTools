# AI usage

Load [SKILL.md](SKILL.md) in the existing agent and supply the successor contract,
selected mode, actual loaded image metadata, transfer state and first-access log.

> Review this stage handoff. Establish the receiving requirements independently,
> trace actual loaded bytes, PC/SP and readiness at transfer, then inspect first
> stack/data accesses. Keep later initialization and other-mode evidence separate.
> Return an obligation table, source-backed findings, gaps and next actions.

Use the [review record](REVIEW.md) or the team's equivalent. No AI SDK, separate
model purchase or DVIT connection is required. The optional helper supports a
bounded record format; the agent can use the team's other native tools directly.
