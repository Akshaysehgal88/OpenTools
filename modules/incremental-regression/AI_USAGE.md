# Regression selection review

Load [SKILL.md](SKILL.md) from the clone or use the
[project-local installer](../../INSTALL.md) with your existing AI agent and model
subscription. No inference SDK or additional model account is required.

## Request

> Inspect this change and the full applicable test manifest. Recommend a first stage with source-backed reasons, mandatory tests and explicit later obligations. Compare actual feedback against the later full campaign.

## Inputs

Provide the independently enumerated universe, change/dependency evidence, current policy, manual map and checker records. Review universe completeness and semantic impact before binding records.

## Review output

Retain the selection, deferred obligations, machine status, all attempts and missed failures. Challenge stale or incomplete maps even when hashes match. The existing runner controls execution; targeted passes cannot qualify omitted tests.

The AI can use existing company tools or a separately validated method beyond the
bundled helper's profile. Preserve the helper's actual findings and label independent
interpretation. Check citations against original artifacts.

Optional [context sources](../../CONTEXT_PORT.md) can supply scoped evidence,
questions and helper descriptions. Standalone use requires no DVIT connection and
never installs DVIT. Bundled scripts do not send records to a model; use the host's
approved data handling for company material.
