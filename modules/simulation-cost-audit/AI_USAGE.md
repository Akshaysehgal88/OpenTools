# Simulation cost review

Load [SKILL.md](SKILL.md) from the clone or use the
[project-local installer](../../INSTALL.md) with your existing AI agent and model
subscription. No inference SDK or additional model account is required.

## Request

> Review these completed run records. Establish clock/window scope, separate wall time from CPU and simulation progress, account for overlap and propose one measured optimization experiment.

## Inputs

Provide stage markers, scheduler/process accounting, native records, workload/checker identity and instrumentation. Use existing measurements before proposing another run. Missing markers are unknown, not evidence of idle time.

## Review output

Retain the timeline, separate resource observations, machine status and a short intervention list. Each proposal needs a measured target, feasibility condition and controlled comparison including setup, replay, collection and review costs.

The AI can use existing company tools or a separately validated method beyond the
bundled helper's profile. Preserve the helper's actual findings and label independent
interpretation. Check citations against original artifacts.

Optional [context sources](../../CONTEXT_PORT.md) can supply scoped evidence,
questions and helper descriptions. Standalone use requires no DVIT connection and
never installs DVIT. Bundled scripts do not send records to a model; use the host's
approved data handling for company material.
