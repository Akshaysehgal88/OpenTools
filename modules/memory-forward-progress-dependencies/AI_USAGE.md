# AI usage

Load [SKILL.md](SKILL.md) in your current agent. Supply allocation/release source,
required actors/resources, mode and traffic-class intent, native prefixes and
completion or blocking observations.

Example request:

> Review this forward-progress dependency chain. Establish who retains each
> resource, the release condition and the capacity needed by the next action.
> Separate candidate cycles from feasible reachable blocking. Check alternate
> channels, early release, external progress and fairness; retain missing premises.

No AI SDK, model purchase or DVIT connection is required. The agent may use the
helper and existing native tools beyond the finite record profile. Optional
context adapters add scoped evidence; they grant no completeness or acceptance
authority.
