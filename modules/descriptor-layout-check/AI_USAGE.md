# Descriptor review

Load [SKILL.md](SKILL.md) from the clone or use the
[project-local installer](../../INSTALL.md) with your existing AI agent and model
subscription. No inference SDK or additional model account is required.

## Request

> Compare this hardware type and firmware representation for the selected target and interface revision. Establish the actual exchanged bytes, check field mappings and save the native evidence and a cited mismatch review.

## Inputs

Provide the RTL type, firmware header or serializer, parameter basis, target ABI and interface policy. Review every field/encoding pairing. Use the qualified frontends or authoritative normalized exports for other targets.

## Review output

Retain layouts, commands, pairing and machine status. Cite differing numeric bit addresses, widths, encodings, size or alignment. A serializer needs wire-format evidence; a layout match does not establish runtime protocol correctness.

The AI can use existing company tools or a separately validated method beyond the
bundled helper's profile. Preserve the helper's actual findings and label independent
interpretation. Check citations against original artifacts.

Optional [context sources](../../CONTEXT_PORT.md) can supply scoped evidence,
questions and helper descriptions. Standalone use requires no DVIT connection and
never installs DVIT. Bundled scripts do not send records to a model; use the host's
approved data handling for company material.
