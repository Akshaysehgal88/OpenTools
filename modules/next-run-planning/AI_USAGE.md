# Next-step planning

Load [SKILL.md](SKILL.md) from the clone or use the
[project-local installer](../../INSTALL.md) with your existing AI agent and model
subscription. No inference SDK or additional model account is required.

## Request

> Inspect these observations and prior attempts. Choose one justified next step, preferably using retained evidence. Explain what each plausible outcome would establish before proposing another simulation.

## Inputs

Provide original run/binary/configuration identities, transaction/time scope, native artifacts and prior decisions. Use [RECORD.md](RECORD.md) or the optional structured ledger. Assess hypothesis plausibility and attainable observations against actual evidence.

## Review output

Keep the original plan and append controls, execution or evidence-only route, observations, interpretation and cost scope. Preserve failed, unexecuted, inconclusive and divergent attempts. A structural pass does not establish that a plan answers the question.

The AI can use existing company tools or a separately validated method beyond the
bundled helper's profile. Preserve the helper's actual findings and label independent
interpretation. Check citations against original artifacts.

Optional [context sources](../../CONTEXT_PORT.md) can supply scoped evidence,
questions and helper descriptions. Standalone use requires no DVIT connection and
never installs DVIT. Bundled scripts do not send records to a model; use the host's
approved data handling for company material.
