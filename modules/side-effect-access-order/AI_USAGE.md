# AI usage

Load [SKILL.md](SKILL.md) in your existing agent. Supply the consumed register
revision, actual access observations, configuration and caller intent references.

Example request:

> Review these acknowledgement and diagnostic accesses. Establish effective field
> semantics and byte lanes from the native sources. Separate actual state changes
> from the caller's permitted effects. Preserve missing hardware/reset or sampling
> premises, and cite the evidence for each finding and next action.

Use local files directly; the optional helper needs no AI SDK. The agent can use
other native tools or follow additional source relationships beyond its scope.
An optional configured context adapter may add scoped evidence. It is not needed
for ordinary use and cannot grant approval or establish completeness by itself.
