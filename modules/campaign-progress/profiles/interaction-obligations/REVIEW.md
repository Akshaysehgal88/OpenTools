# Interaction evidence handoff

- **Scope:** original claim, required interaction population, configuration and owner.
- **Relationship:** shared resource, producer/consumer, risk consequence and bound
  source revision. Distinguish design evidence from interpretation or hypothesis.
- **Applicability:** applicable, reviewed nonapplicable or unresolved, with source,
  explicit mode facts and review basis. Preserve excluded rows.
- **Execution:** original scenario/run, source/runtime identity, clock/reset, observed
  combined trigger and retained window.
- **Checking:** linked native points, enable/actions, original result and witness;
  keep unknown oracle/instrumentation semantics visible.
- **Conclusion:** supported selected obligations, differences and missing evidence.
- **Action:** retained evidence to retrieve or targeted proposal, receiving owner and
  affected recheck. No action when evidence answers the bounded question.
- **Limits:** no exhaustive interaction set, verification completeness or signoff claim.

Attach inputs and JSON/Markdown if using the helper. Parent campaign coverage
counts only the declared named obligations; it creates no new combinations.
