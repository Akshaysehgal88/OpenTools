# Campaign review

Load [SKILL.md](SKILL.md) from the clone or use the
[project-local installer](../../INSTALL.md) with your existing AI agent and model
subscription. No inference SDK or additional model account is required.

## Request

> Review these cumulative exports against the original objectives. Separate coverage change, effective workload, required execution and costs. Inspect the native counter sources and recommend the next action.

## Inputs

Provide the independent objective contract, required population, policy, cumulative exports and source/counter definitions. Preserve native states and missing/unexecuted work. Use separately qualified methods for statistical objectives.

## Review output

Retain machine status and source citations, including corrections to falsely qualified counters. Changed definitions need separate treatment. Event counts are not independent trials, and the helper grants no campaign stopping or release authority.

The AI can use existing company tools or a separately validated method beyond the
bundled helper's profile. Preserve the helper's actual findings and label independent
interpretation. Check citations against original artifacts.

Optional [context sources](../../CONTEXT_PORT.md) can supply scoped evidence,
questions and helper descriptions. Standalone use requires no DVIT connection and
never installs DVIT. Bundled scripts do not send records to a model; use the host's
approved data handling for company material.
