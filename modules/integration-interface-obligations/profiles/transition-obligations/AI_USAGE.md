# AI usage

Load the parent's skill and this [workflow](WORKFLOW.md) in your current agent.
Supply the exact protocol/version, independent participant/obligation contract,
source, message identities and actual permission/consumer observations.

Example request:

> Review this transient ownership/completion path. Establish remaining obligations
> by source, resource and epoch, then inspect the accepted token and actual consumer
> use. Keep data and release prerequisites separate. Challenge counters, stable
> labels, duplicate replies and missing participants against source.

No AI SDK, model purchase or DVIT connection is required. The agent may use existing
native methods beyond the helper. Optional context grants neither completeness nor
acceptance authority.
