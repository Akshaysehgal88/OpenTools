# Interface integration review

Load [SKILL.md](SKILL.md) in your existing AI host or use the
[project-local installer](../../INSTALL.md). No model SDK/account is required.

> Review these connected endpoints and the selected configuration. Identify what
> each request, receipt, completion and cancellation event actually guarantees,
> compare the consumer's assumptions, and retain a cited obligation table. Use
> existing native traces before requesting another run.

Provide endpoint source/contracts, mode/revision, native bindings, clock/reset
basis and relevant event observations. [RECORD.md](RECORD.md) is optional; use the
organization's existing review format if it retains the same useful evidence.

A favorable direct-port report cannot establish semantic compatibility. Inspect
logic that consumes events, including bridges and cancellation after commit. Keep
unsupported or partial captures visible. A different expression may be a valid
adapter rather than a wiring fault; validate that transformation natively.

Retain the native status, actual observed event order, source-cited interpretation,
unresolved assumptions and the next justified check. Qualified company methods can
extend the bundled profile. Optional [context sources](../../CONTEXT_PORT.md) can
provide scoped roles and relationships; standalone use never requires or installs
DVIT. The helper itself transmits nothing to a model.
