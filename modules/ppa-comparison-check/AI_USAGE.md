# PPA review

Load [SKILL.md](SKILL.md) from the clone or use the
[project-local installer](../../INSTALL.md) with your existing AI agent and model
subscription. No inference SDK or additional model account is required.

## Request

> Review these saved PPA runs against the intended experiment. Define the comparison per metric, identify confounders and missing conditions, then save the report and a cited interpretation of the deltas.

## Inputs

Provide original metric reports, units/scope, RTL/netlist/tool/library/constraint identities and the intended variable. Power also needs activity and annotation evidence. Review condition roles and any equivalence record against the sources.

## Review output

Retain the contract, native measurements, machine status and condition citations. Separate arithmetic change from a supported engineering claim. A valid contract cannot prove causal attribution or the truth of supplied declarations.

The AI can use existing company tools or a separately validated method beyond the
bundled helper's profile. Preserve the helper's actual findings and label independent
interpretation. Check citations against original artifacts.

Optional [context sources](../../CONTEXT_PORT.md) can supply scoped evidence,
questions and helper descriptions. Standalone use requires no DVIT connection and
never installs DVIT. Bundled scripts do not send records to a model; use the host's
approved data handling for company material.
