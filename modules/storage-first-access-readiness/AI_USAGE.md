# AI usage

Load [SKILL.md](SKILL.md) in your current agent. Supply the consumed wrapper,
geometry, initialization/reset policy, first-master intent and raw transaction
observations.

Example request:

> Review whether this memory is ready for its first consumers. Follow partial
> writes into internal reads, identify who initializes each required word and
> compare coverage at release and access. Check ECC correction/merge and abort
> behavior against the actual code family. Retain missing or stale evidence.

No AI SDK, model purchase or DVIT connection is required. The agent may use the
helper, native tools and source relationships beyond the owned profile. Optional
context adapters supply scoped evidence; they grant no completeness or acceptance
authority.
