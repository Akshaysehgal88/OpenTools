# Contract change review

Load [SKILL.md](SKILL.md) from the clone or use the
[project-local installer](../../INSTALL.md) with your existing AI agent/subscription.

> Review this changed interface contract. Establish maximum outstanding demand,
> usable consumer capacity and the actual admission/retirement behavior. Compare
> the selected native configuration, inspect dependent assumptions and retain a
> cited conclusion with the next evidence needed, if any.

Provide original/current source or elaborated exports, the interface obligation,
mode/configuration, sharing/reservation rules and available native observations.
The optional helper checks supplied integer bounds; it does not infer their roles.

Inspect the producer and consumer even when metadata produces a favorable report.
A smaller numeric parameter may control a watermark or number of banks rather
than the true outstanding limit. Keep the original report and append the sourced
correction. A declared premise without actual support stays unresolved.

Retain native values, source locations, machine status, independent interpretation
and missing dependencies. Use another native/company method when the question is
outside the helper's profile, with its own validation. No inference SDK or model
account is installed. Optional [context sources](../../CONTEXT_PORT.md) can supply
scoped intent and relationships; absence never triggers DVIT installation.
